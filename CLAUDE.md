# ArchLine — istruzioni per chi lavora sul codice (Claude Code locale o cloud)

## Progetto
Fork di [Open CAD Studio](https://github.com/HakanSeven12/OpenCADStudio) (Rust, iced; app GPL-3.0, codec DWG/DXF MPL-2.0). Nome: **ArchLine**. Obiettivo: workspace "AutoCAD classico" (barre Draw/Modify docked, riga di comando, palette) e, in seguito, uno strato architettonico come plugin (locali, abachi, IFC, quantità con fonte e stato).
Utente: Mauro Mazzarelli, architetto a Roma. Rispondere **in italiano**, da pari a pari, prima il deliverable. **Nessun valore inventato** su prezzi, quantità, calcoli; distinguere dato deterministico (IFC/DXF) da dato desunto da raster/PDF (bozza da verificare). Se il tipo di intervento (nuova costruzione, ristrutturazione, manutenzione, restauro) è ambiguo, chiedere prima.

## Build e test
```
cargo check --locked
cargo build --release --bin ArchLine             # target\release\ArchLine.exe
cargo test --locked --lib classic_toolbar        # altri filtri: start, i18n
python -m pip install ezdxf                       # una volta, per il banco di conformità
python -m unittest discover -s tests/conformance -p "test_*.py"   # test del banco (102 test, ~45 s, con quelli del banco BIM)
python tests/conformance/run.py target\release\ArchLine.exe  # misura DXF/DWG con oracolo ezdxf (~35 s)
cargo test --locked --lib bim::                  # modulo BIM; poi --lib app::bim_tests (flussi dall'app) e --lib commands::bim_a (AL_ALTEZZA, AL_ABACO, AL_ABACO_CSV: fuori da bim::)
python tests/conformance/bim_extract.py target\release\ArchLine.exe  # estrazione e abaco BIM letti con ezdxf (181 controlli OK/FALLITO)
```
- `.cargo/config.toml`: `RUST_MIN_STACK` è a 64 MiB (upstream 8 MiB). Non rimuoverlo: senza, `rustc` è andato in stack overflow su Windows in release.
- **CI su GitHub: SPENTA per volere dell'utente (2026-10-21).** GitHub Actions è disabilitato sul repo `Ilmazza/ArchLine` (impostazione del repo, non i file): niente corse a ogni push, nessun artefatto, nemmeno le CI di upstream. **Non riattivarla, non aggiungere workflow, non proporre di "vedere cosa dice la CI"**: si verifica in locale (`cargo check`, `cargo test --lib <filtro>`, `cargo build --release --bin ArchLine`, banco di conformità, `build-msi.ps1`), con le build che consegniamo noi. I file in `.github/workflows/` restano com'erano (sono di upstream o storici, toccarli darebbe conflitti nei merge); `archline-windows.yml` è inerte. Per riaccenderla (solo su richiesta esplicita): `gh api -X PUT repos/Ilmazza/ArchLine/actions/permissions -F enabled=true`. Le voci sotto che parlano di CI (Python host check, `Tests`, Web build check, artefatti `ArchLine-windows-N`) valgono solo come storia.
- Il container cloud non ha GPU: la verifica visiva si fa solo su Windows, con screenshot dell'utente.

## Branch e flusso
- L'utente lavora in locale su `lavoro` (nata da `claude/archline-integration`, poi cancellato); GitHub è il backup (`git add -A`, `git commit`, `git push`).
- Il lavoro assistito va su branch `claude/…`; si unisce con PR. Non pushare su `lavoro` mentre l'utente lavora.
- `main` del fork = upstream: **non toccarlo senza conferma esplicita**. Upstream: `HakanSeven12/OpenCADStudio` (`git remote add upstream …`, merge periodico a lavoro salvato).

- BIM, **modello** (tutto nel DWG): una **zona** è una `HATCH` solida non associativa nel modello con XDATA `ARCHLINE_ZONA` (stato, origine, varco, asse/spessore/altezza se presenti; l'altezza non la riempiamo mai da soli: la scrivono solo `AL_STATO Altezza` e, dalla parte 2, `AL_ALTEZZA`) su `AL-DEMOLIZIONI` (ACI 2, giallo) o `AL-NUOVE` (ACI 1, rosso); un **locale di fatto** è una `LWPOLYLINE` su `AL-LOCALI` più un `MTEXT` con nome e «= N,NN m²» (XDATA `ARCHLINE_LOCALE`); un **locale di progetto** è solo il seme (`MTEXT` su `AL-LOCALI-PROGETTO`): forma e area si ricalcolano sempre. Le impostazioni (unità, layer dei muri nuovi) stanno nel record `ARCHLINE_PROGETTO` (XRecord nel dizionario radice). Unità mm/cm/m da `INSUNITS`: con 0 si **chiede** e si salva nel record, le altre si rifiutano, **`INSUNITS` non si scrive mai**. Aree in m² con virgola e due decimali (`format_m2`: 11,905 → «11,91»). Muri = solo `LINE`, `ARC`, `LWPOLYLINE`, `POLYLINE` 2D del modello su layer accesi e non congelati (i bloccati contano), mai `AL-*`; **le parti dei locali non sono mai muri** (esclusione per handle di `rooms_in`, cioè per XDATA, su qualunque layer: `walls::wall_set_without_rooms`, R67, la usano `AL_LOCALE`, `AL_AGGIORNA`, le zone e l'estrazione; `wall_set` filtra solo per tipo e layer e resta per i test); testi, quote, blocchi, campiture e immagini non sono muri, e ciò che disturba si spegne come in AutoCAD.
